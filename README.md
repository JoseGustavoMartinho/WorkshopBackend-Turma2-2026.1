# Sistema de Cadastro de Pessoas (CRUD)

## 📌 Sobre o projeto
Este projeto foi desenvolvido como atividade prática durante minha participação na **Fábrica de Software** da faculdade.

O objetivo foi aplicar conceitos de desenvolvimento back-end utilizando Django, incluindo a implementação de um sistema CRUD completo.

## 🚀 Funcionalidades
- Cadastro de pessoas
- Listagem de pessoas
- Edição de dados
- Exclusão com confirmação

## 🛠 Tecnologias utilizadas
- Python
- Django
- HTML
